# Brojač minuta

Web-aplikacija za brojanje minuta po zadacima (smetnje, uključenja, pozivi s tehničarem, dodatni poslovi), s dnevnikom, riješenim zadacima, statistikom i više korisnika.

## Postavljanje na GitHub (jednom)

1. Na github.com napravi novi repozitorij, npr. `brojac-minuta` (može biti *Public*).
2. Klikni **Add file → Upload files** i prenesi sve iz ove mape: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md` i cijelu mapu `icons`. Klikni **Commit changes**.
3. Idi na **Settings → Pages**. Pod *Branch* odaberi `main` i mapu `/ (root)`, pa **Save**.
4. Nakon minutu-dvije aplikacija je na adresi `https://TVOJE-IME.github.io/brojac-minuta/`.

## Instalacija na računalo

1. Otvori tu adresu u **Chromeu** ili **Edgeu**.
2. U adresnoj traci klikni ikonu za instalaciju (ekran sa strelicom) ili izbornik ⋮ → **Instaliraj Brojač minuta**.
3. Aplikacija dobiva svoju ikonu i otvara se u vlastitom prozoru. Radi i bez interneta.

Na mobitelu: otvori adresu → izbornik → **Dodaj na početni zaslon**.

## Ažuriranje

Kad promijeniš `index.html`, ponovno ga prenesi na GitHub. Aplikacija povuče novu verziju sljedeći put kad je otvoriš s internetom.

## Gdje se spremaju podaci

Zadaci, korisnici i statistika spremaju se u preglednik na uređaju na kojem koristiš aplikaciju. Svaki kolega na svom računalu ima svoje podatke. Ako obrišeš podatke preglednika, brišu se i zadaci.
